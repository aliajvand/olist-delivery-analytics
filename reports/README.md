# Reports

Everything a reader should be able to look at without running anything: figures, metric tables, the decision policy and the model card.

These files **are committed on purpose**. A portfolio repository whose evidence is gitignored shows a recruiter an empty folder.

| item | what it is |
|---|---|
| `figures/` | charts. Every one carries an insight computed at runtime, so refreshing the data can never leave a stale claim on a chart. |
| `models/` | metric tables, leaderboards, threshold policies and the governance summary. |

_Part of **Olist Delivery Performance Analytics**. Project overview: [`../README.md`](../README.md)._
